Why we built it

Formatting eats time that should go into thinking

Building a deck by hand

  • Layout rebuilt for every deck
  • Fonts and colours drift between authors
  • Late edits break the alignment
  • Feedback arrives about the layout

Building a deck in Platypus

  • Layout comes from the brand
  • One type and colour system throughout
  • Edits are text, so nothing shifts
  • Feedback stays on the argument

What we wanted instead

  • Write the content, once
  • Let the brand decide how it looks
  • Change a slide without rebuilding the deck
  • Hand over something the client can edit
